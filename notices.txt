Если в ветке dev нужно сохранить изменения:

git add main.py ( .) # указываем конкретный файл или пробел/точка - все файлы
git commit -m "correction"
git push origin dev # сохранение копии в GitHub (на ветке dev)

Далее, делаем слияние с веткой main и сохраняем копию на ветке main в GitHub:

git checkout main # перехожу на ветку main
git merge dev
git push origin main # сохранение копии в GitHub (на ветке main)


git checkout dev # переход опять с ветки main на ветку dev

git restore main.py # откат файла к последнему коммиту
git restore . # откат сразу всех файлов к последнему коммиту
